# 🧬 Computational Science & Kinetic Modeling

I built this repo because dealing with complex scientific systems requires strict logic and heavy computational lifting. It's not just about running numbers; it's about stressing mathematical constraints to see where they break.

### ⚙️ What's inside:
- **kinetics_simulation.py**: A custom script I wrote to model first-order chemical reaction decay and exponential concentration profiles. It automates rate constant extraction and tests the kinetic data against theoretical limits.

### 🧠 Why this matters for AI Evaluation:
If an AI model hallucinates or fails at algorithmic reasoning, it's useless for advanced STEM tasks. The rigorous numerical simulations and curve-fitting constraints I use here show my ability to evaluate and benchmark how well frontier LLMs reason through complex, high-variance logic puzzles.
